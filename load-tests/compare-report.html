Load test report (API/HTTP)

Artillery · generated · lower latency is better

End-to-end HTTP: the web framework, JSON handling and the server's concurrency model are part of every number, and a large share of short requests. Every service runs the same artillery.yml at the same constant arrival rate, chosen so each should keep up; a median rising to seconds means a service is saturated, not just slower. Languages are compared within one SEARCH_MODE profile: baseline runs a single-threaded scan per request; parallel splits each file scan into chunks, and /search/many also runs one task per word length. With several rounds, bars show the median and whiskers the min–max across rounds.
